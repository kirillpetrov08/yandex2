# Политика конфиденциальности приложения «Конвертер+»

Дата последнего обновления: 15.10.2026

## 1. Общие положения

Настоящая Политика описывает, какие данные обрабатываются при использовании мобильного
приложения «Конвертер+» (далее — Приложение), пакет `com.converterplus.app`, и как они защищены.

Оператор: Индивидуальный разработчик (далее — Оператор).
Контакт для обращений: **support.converterplus@gmail.com**

## 2. Главный принцип

**Ваши файлы не покидают устройство.** Конвертация изображений и PDF выполняется
исключительно локальными средствами Android на вашем телефоне. Файлы не загружаются
на серверы Оператора или третьих лиц, не копируются и не анализируются.

Приложение не запрашивает и не использует разрешения на доступ к хранилищу, камере,
микрофону, контактам и геолокации.

## 3. Какие данные обрабатываются

### 3.1. Данные, которые хранятся только на устройстве
- выбранные вами настройки (тема, качество, папка сохранения);
- история конвертаций (имя файла, формат, размер, дата) — в приватной папке Приложения;
- временные копии файлов — в кэше Приложения, удаляются автоматически через 24 часа
  или при очистке кэша системой.

Эти данные никуда не передаются и доступны только вам.

### 3.2. Данные, обрабатываемые рекламными сервисами
Приложение показывает рекламу сети Яндекс (РСЯ) с помощью Yandex Mobile Ads SDK.
SDK активируется **только после вашего согласия** (экран онбординга, третий шаг).

Рекламный SDK может обрабатывать:
- рекламный идентификатор устройства (Android Advertising ID);
- технические параметры устройства и версию ОС;
- данные о показах и взаимодействиях с рекламой (показ, клик, просмотр видео);
- примерное местоположение на уровне города — **только если определено самим SDK**;
  Приложение намеренно передаёт в SDK признак `setLocationTracking(false)` и
  геолокацию не собирает.

Персонализированная реклама включается отдельным переключателем
(онбординг → «Персонализированная реклама», Настройки → «Персонализированная реклама»).
При выключенном переключателе реклама показывается неперсонализированной.

Подробнее об обработке данных рекламными сервисами Яндекса:
https://yandex.ru/legal/confidential/ и https://yandex.ru/legal/mobile_ads_terms/

Отказ от персонализации рекламы: Настройки → Реклама → выключить
«Персонализированная реклама», либо сброс рекламного идентификатора в настройках Android
(Настройки → Google → Реклама → Сбросить рекламный идентификатор).

## 4. Какие данные НЕ обрабатываются

- содержимое ваших файлов;
- фотографии, документы, контакты, сообщения;
- точное местоположение;
- данные аккаунтов (в Приложении нет регистрации и входа).

## 5. Разрешения, которые запрашивает Приложение

| Разрешение | Зачем |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | загрузка и показ рекламы |
| `POST_NOTIFICATIONS` | прогресс конвертации в шторке (спрашиваем при первой конвертации, можно отказать) |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_DATA_SYNC` | конвертация продолжается, когда приложение свёрнуто |

Разрешений на хранилище нет: файлы выбираются системными окнами выбора,
сохранение выполняется через системные механизмы MediaStore/SAF.

## 6. Хранение и защита

Данные хранятся в приватной области Приложения, недоступной другим приложениям.
Рекламные запросы передаются по защищённому соединению (HTTPS).

## 7. Дети

Приложение не предназначено для детей младше 13 лет и не собирает данные детей knowingly.

## 8. Изменения Политики

Оператор может обновить Политику. Актуальная версия всегда доступна по адресу
`https://kirillpetrov08.github.io/yandex2/privacy_policy.html` (хостинг включается в
Settings → Pages, см. `docs/ADS_SETUP.md`, раздел 3.3), дата обновления указана в начале.

## 9. Контакты и удаление данных

По вопросам обработки данных, а также для удаления рекламного идентификатора
из рекламных систем обращайтесь: **support.converterplus@gmail.com**.
Ответ предоставляется в течение 30 дней.

Удалить все локальные данные можно в любой момент:
Настройки Android → Приложения → Конвертер+ → Хранилище → Очистить данные.
