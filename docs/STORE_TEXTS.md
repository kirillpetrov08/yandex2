# Тексты для магазинов — Копилка

## Коротко

Название: **Копилка — Финансы офлайн** (до 30 симв.)
Краткое: **Учёт расходов и доходов без интернета** (до 80)
Категория: Финансы / Инструменты
Возраст: 0+ (нет контента 12+, без покупок)
Реклама: Да, Яндекс РСЯ
Покупки: Нет

## Полное описание

Копилка — офлайн учёт финансов. Все данные на устройстве, без регистрации и подписок.

**Что умеет:**
- Счета: наличные, карта, накопления
- Категории: продукты, транспорт, жильё, подписки, развлечения, здоровье, доходы
- Операции: расход, доход, перевод — сумма, категория, счёт, дата, комментарий, фото чека
- Бюджеты: лимиты на месяц по каждой категории, видно остаток и превышение
- История: поиск и фильтры, группы Сегодня / Вчера / Ранее
- Статистика: графики по категориям и периодам, баланс, итоги
- Повторы: напоминания о платежах (ежедневно/еженедельно/ежемесячно)
- Экспорт: CSV/PDF в Загрузки или свою папку

**Почему удобно:**
- Работает без интернета, данные не уходят на сервер
- Не просит доступ к файлам, камере, микрофону
- 3 нажатия до записи траты, большие кнопки, тёмная тема
- Фоновая обработка, прогресс в шторке (по желанию)

**Монетизация:**
Только реклама Яндекс РСЯ (баннер, межстраничная, ролик за вознаграждение). Подписок и покупок нет. За просмотр ролика реклама скрывается на 30 минут.

**Приватность:**
Файлы не собираются, файлы чеков — только ваши фото чеков, хранятся локально. Рекламные ID — через SDK Яндекса после согласия.
