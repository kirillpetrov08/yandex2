Политика конфиденциальности приложения «Конвертер+»

Дата последнего обновления: 15.10.2026

1. Общие положения

Настоящая Политика описывает, какие данные обрабатываются при использовании мобильного приложения «Конвертер+» (пакет com.converterplus.app), и как они защищены.

Оператор: индивидуальный разработчик. Контакт для обращений: support.converterplus@gmail.com

2. Главный принцип

Ваши файлы не покидают устройство. Конвертация изображений и PDF выполняется локальными средствами Android на вашем телефоне. Файлы не загружаются на серверы Оператора или третьих лиц.

Приложение не запрашивает разрешения на доступ к хранилищу, камере, микрофону, контактам и геолокации.

3. Какие данные обрабатываются

3.1. Только на устройстве: настройки (тема, качество, папка сохранения), история конвертаций (имя файла, формат, размер, дата), временные копии файлов в кэше (удаляются автоматически через 24 часа). Эти данные никуда не передаются.

3.2. Рекламными сервисами: Приложение показывает рекламу сети Яндекс (РСЯ) через Yandex Mobile Ads SDK. SDK активируется только после вашего согласия. Рекламный SDK может обрабатывать рекламный идентификатор устройства, технические параметры устройства и версии ОС, данные о показах и взаимодействиях с рекламой, а также примерное местоположение на уровне города, определённое самим SDK. Приложение намеренно не передаёт геолокацию (setLocationTracking(false)).

Персонализированная реклама включается отдельным переключателем в онбординге и в настройках. При выключенном переключателе реклама показывается неперсонализированной.

Подробнее: Политика конфиденциальности Яндекса.

4. Какие данные НЕ обрабатываются

Содержимое ваших файлов, фотографии и документы, контакты, точное местоположение, данные аккаунтов (в Приложении нет регистрации).

5. Запрашиваемые разрешения

РазрешениеЗачем
INTERNET, ACCESS_NETWORK_STATEзагрузка и показ рекламы
POST_NOTIFICATIONSпрогресс конвертации в шторке (можно отказать)
FOREGROUND_SERVICE, FOREGROUND_SERVICE_DATA_SYNCконвертация в фоне

Разрешений на хранилище нет: файлы выбираются системными окнами выбора, сохранение выполняется через системные механизмы MediaStore/SAF.

6. Хранение и защита

Данные хранятся в приватной области Приложения, недоступной другим приложениям. Рекламные запросы передаются по HTTPS.

7. Дети

Приложение не предназначено для детей младше 13 лет.

8. Изменения Политики

Актуальная версия всегда доступна по этой ссылке; дата обновления указана в начале страницы.

9. Контакты и удаление данных

По вопросам обработки данных пишите: support.converterplus@gmail.com. Ответ в течение 30 дней.

Удалить локальные данные: Настройки Android → Приложения → Конвертер+ → Хранилище → Очистить данные.
